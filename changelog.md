# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-27

### Added

- Initial project structure with README.md.
- Cypress test framework with configuration (`cypress.config.js`), example E2E test (`cypress/e2e/test.cy.js`), fixtures (`cypress/fixtures/example.json`), and support files (`cypress/support/commands.js`, `cypress/support/e2e.js`).
- Playwright test framework with configuration (`playwright.config.ts`) and example spec (`tests/example.spec.ts`).
- `.gitignore` files for both Cypress and Playwright projects.
- `package.json` and `package-lock.json` for both Cypress and Playwright projects.
- Comprehensive README documentation including project structure, technologies used, and instructions for running tests.

### Changed

- Expanded README.md with full project documentation including structure overview, technology stack, and step-by-step instructions for running both Cypress and Playwright test suites.
